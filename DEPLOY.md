# Deploying docs.saturday.fit

Operator runbook for the documentation site: hostnames, DNS, rebuilds, site configuration, and where the machine-readable files come from. Mintlify serves only the pages listed in `docs.json` navigation, so nothing in this file reaches the site. This repository is public, so keep secrets out of it all the same.

## Hostnames

| Host | What it serves |
|------|----------------|
| `docs.saturday.fit` | The documentation site, hosted on Mintlify |
| `api.saturday.fit` | The API itself, including the MCP endpoint at `/mcp` |

The sandbox base URL is issued with each `sk_test_` key. Requesting a docs path on `api.saturday.fit` returns the API's `404`, not a page. `GET https://api.saturday.fit/v1/` is the discovery index and its `documentation` link points at this site.

## DNS

| Record type | Name | Target | Proxy |
|------------|------|--------|-------|
| CNAME | `docs` | `cname.mintlify-dns.com` | DNS only (grey cloud) |

Cloudflare proxy stays disabled on the Mintlify CNAME. Mintlify terminates SSL and needs direct DNS resolution.

To verify a DNS change: `dig docs.saturday.fit CNAME` answers `cname.mintlify-dns.com.`, `https://docs.saturday.fit` loads the site, and Mintlify issues the certificate.

## Deploying

Mintlify deploys from Git: a merge to `main` rebuilds the site. A rebuild can also be triggered by hand from [dashboard.mintlify.com](https://dashboard.mintlify.com) on the Saturday API project.

Two checks run on every pull request from `.github/workflows/`. Engine Constants (GitHub-hosted) fails the PR if a page prints an engine value. Docs Drift asks for the self-hosted runner, which does not accept jobs from a public repository, so it queues until it is cancelled: run it locally instead (README, "Local checks") and cancel the queued run. The fuel-backend copy of the same check runs on backend pull requests and catches the other direction.

## Site configuration

`docs.json` at the repository root configures the site, against the [Mintlify `docs.json` schema](https://mintlify.com/docs.json).

| Setting | Value |
|---------|-------|
| Theme | `mint` |
| Primary color | `#1aabb8` (Saturday teal) |
| Light / dark accent | `#8FC5CE` / `#0e7e8a` |
| Tabs | Coaching, API Guides |
| Contextual actions | Copy, view, open in Claude, open in Cursor |
| Feedback | Thumbs rating, suggest edit, raise issue (the last two open against this public repository) |

Moving or renaming a page needs a `redirects` entry in `docs.json` so the old URL keeps resolving. `npx mint@latest broken-links --check-anchors` catches an internal link or anchor that no longer resolves.

## Content structure

```
docs/
  docs.json              # Site configuration and navigation
  llms.txt               # Hand-curated LLM index
  introduction.mdx       # Landing page
  access.mdx             # Getting a key
  quickstart.mdx
  authentication.mdx
  error-handling.mdx
  rate-limiting.mdx
  coaching/              # Coaching tab: onboarding, billing, roster, team, nutrition
  guides/                # API Guides tab: core, integration, coach API, platform
  snippets/              # Shared JSX components
  images/                # Logos, favicon, brand marks
  scripts/               # Local checks (README)
```

## Machine-readable files

| URL | Source |
|-----|--------|
| `https://docs.saturday.fit/llms.txt` | `llms.txt` in this repository, hand-curated |
| `https://docs.saturday.fit/llms-full.txt` | Generated by Mintlify from the MDX corpus on every build. Never commit one; it would shadow the generator |
| `https://api.saturday.fit/mcp` | Served by the API (fuel-backend `cmd/partner-api`), not by this site |
