# About This Documentation

These pages are published at `docs.saturday.fit` from the public [SaturdayInc/docs](https://github.com/SaturdayInc/docs) repository. They describe the current `/v1` API at `https://api.saturday.fit`, and the API's discovery document at `GET https://api.saturday.fit/v1/` links back here. Agents can read the same content as [llms.txt and llms-full.txt](/guides/mcp-integration#llm-discoverability); the MCP endpoint is covered in [MCP Integration](/guides/mcp-integration). To report an error in the documentation, [open an issue](https://github.com/SaturdayInc/docs/issues/new) or write to [api@saturday.fit](mailto:api@saturday.fit). API outages and incidents go to the same address.
